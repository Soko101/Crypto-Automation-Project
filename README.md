# Crypto-Automation-Project

This project collects and analyzes live cryptocurrency data using the CoinMarketCap API. It 
automates data retrieval, stores historical data, and visualizes trends.

## What I Did

- Connected to the CoinMarketCap API to pull the top 100 cryptocurrencies.
- Automated hourly data collection with timestamping.
- Cleaned and structured the API response using pandas.
- Appended results to a CSV file for long-term tracking.
- Visualized price changes and volatility over time.

## Visualizations

Includes:
- Line charts of coin prices over time
- Percent change comparison (1h, 24h, 7d, etc.)
- Correlation heatmaps for market movement
